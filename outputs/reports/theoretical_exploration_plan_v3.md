# 第三轮多理论框架与开放式探索计划

## 范围

- 运行编号：`20260723_multi_theory_abductive_v3`
- 经验基础：第二轮已清洗的 35 份问卷、3 个唯一链接个案、84 条已验证质性片段及 75 条问卷—访谈裁决。
- 文献边界：只使用 `docs/literature_context/` 冻结的 73 项来源；文献用于解释，不替代参与者证据。
- 不重新筛选样本，不新增无理论依据的显著性搜索，不修改 canonical codebook。

## 执行顺序

1. 建立理论卡片，明确概念、分析单位、资料匹配、盲点和套用风险。
2. 按五个相互独立角色进行边界/归属、制度/身份、中介/能动性、数字关系、过程/替代解释再分析。
3. 主 agent 逐项核对代理证据，建立跨框架矩阵并评价 `strong fit / moderate fit / weak fit / not supported`。
4. 对异常组合、不同路径、相似困难、事件链、制度—关系—数字交叉及沉默开展溯因分析。
5. 提出非因果的组合分析框架及可反驳机制命题。
6. 由两个独立 reviewer 审查理论贴合与证据平衡；主 agent 逐项处置。
7. 生成第三版报告、自动验证、Git commit 与下一个未占用 tag。

## 证据与判定规则

- 经验陈述和理论解释分栏；每项代理结论必须同时给出问卷变量/表格与访谈参与者/行号。
- `SILENCE` 只表示资料覆盖不足，不表示经验不存在。
- 每个理论角色至少提交一个反例或框架失败点，并列出非文化竞争解释。
- 公开产物不披露问卷序号、内部行 ID、第三案例匿名代号、其行号或稀有背景组合；完整证据保留在忽略 Git 的代理目录。
- 机制命题只允许：`cross-framework robust`、`framework-dependent`、`plausible but under-evidenced`、`contradicted`、`unsupported`。
- 只有前两类进入第三版主体；证据不足项进入限制/后续研究，矛盾或不支持项不得写成发现。

## 代理输出契约

每个理论角色在独立目录生成：

- `analysis_memo.md`
- `framework_coded_evidence.csv`
- `rival_explanations.csv`
- `framework_limits.md`

所有代理只写自身目录，不改报告、代码本或 canonical 文件。审查代理只写审查意见，主 agent 负责验证、修订和公开层脱敏。
