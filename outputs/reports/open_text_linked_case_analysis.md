# 开放题与三份链接访谈三源对照

## 资料范围

三名链接个案的Q8.1和Q8.2共6条回答全部进入三源对照。受限CSV保留访谈文件、匿名参与者代码及行号；本公开报告只使用 `public_text_id` 和“链接个案”表述。六条对照中，`CONVERGENCE` 为1条，`EXPANSION` 为5条；没有满足同构念、重叠时段且方向相反三条件的严格分歧。

## 个案内对应

### OT-R23-Q81 与 OT-R23-Q82 对应的链接个案

Q8.1把不能迅速找到组员写成距离来源。访谈只能确认小组讨论与汇报在课程中占重要位置，没有逐字重现一次组队受阻；封闭题对后期小组排除为不确定。因此，这是一项低置信度扩展：任务结构提供了语境，但不能据此断言遭到同伴排斥。

Q8.2只说希望多询问插班生情况。封闭题显示该个案曾获得并认可朋辈支持，访谈进一步列出同伴主动帮助、解释和介绍环境。三源关系说明“已有帮助”和“仍希望有人主动了解”可以并存，但开放回答过短，不能判定支持对象、频率或未满足程度。

### OT-R35-Q81 与 OT-R35-Q82 对应的链接个案

Q8.1同时报告小组邀约带来的进入感与本地成长话题造成的距离。后期成员感封闭题方向较正面，访谈也概括同学在初期会照顾和解释；但访谈没有复述开放题中的本地参照距离。因此，访谈支持进入面，只对混合结构作部分扩展，不能把一面覆盖另一面。

Q8.2从群体层面提出适应新环境、旧关系负担和关注需要。个人封闭题表示不需要正式情绪或反排斥支持；访谈又说明过度显眼的教师特别关心可能增加压力。这不是严格矛盾，而是把“支持”限定为强度适当、不过度特殊化、尊重个人偏好的支持。

### OT-R18-Q81 与 OT-R18-Q82 对应的链接个案

Q8.1与封闭题、访谈对同桌主动交谈、放慢语速和午餐邀请形成最清楚的三源汇聚。访谈补充了互动顺序和日常细节，但同一显著记忆在两种资料中重现，不能当成两个独立案例重复计数。

Q8.2建议兼顾语言、课程差异和教师协助分组。封闭题显示已经获得若干支持，其中朋辈支持被评为有限；访谈则解释自由分组时不认识任何人如何限制参与。三源共同把“分组”显示为制度安排与关系机会交叉的场景，但不能确认教师分配会产生持续友谊。

## 开放题作为证据桥梁的作用与边界

开放题确实位于35份封闭问卷与3份深度访谈之间：它在26名回答者中提供事件、支持形式和参与者用语，使封闭类别获得过程含义；对三个链接个案，又可由访谈补充人物、顺序和背景。然而，这座桥梁不能消除证据层差异：

- 26名开放题回答者是自选子样本，不等于35人完整样本；
- 三份访谈只深入其中三人，不代表其余开放回答；
- 同一个人的问卷与访谈不是独立重复证据；
- 访谈追问和开放题长度不同，沉默可能是未问、未忆及或未选择表达；
- 三源对照适合识别汇聚、扩展和条件限制，不足以证明机制或因果路径。
