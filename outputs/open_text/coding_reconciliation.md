# Q8.1/Q8.2 独立编码协调记录

## 输入、覆盖与独立性

本综合只比较以下两套已经完成、彼此独立的编码：

- 归纳式路径：52条逐回答编码、44个细粒度候选代码；
- 研究问题与理论引导路径：52条逐回答编码、47个实际使用的标签，以及框架贴合与无法归类记录。

两套文件与受限语料的 `public_text_id` 完全一致；Q8.1和Q8.2各26条、共52条均有实质语义判断，没有漏行。语料中另有18个空白框架行，不属于本代理被要求编码的52条可分析回答。所有计数以 `public_respondent_id` 去重；本语料中每名回答者每题只有一条回答。

## 协调原则

1. 先以原文和归纳式语义摘要确定“发生了什么”，再用理论路径限定可以怎样解释。
2. 将两路径中的同义标签合并，例如 `GROUPWORK_ENTRY` 合并入 `COLLABORATIVE_TASK_ENTRY`，`NEED_RULE_EXPLANATION` 合并入 `ASSESSMENT_AND_RULE_CLARITY`。
3. 保留经验上真正不同的代码，例如听说语言可理解性与本地共同参照缺口、实际获得支持与希望获得支持、同伴邀请与任务后的关系延伸。
4. 不把关键词命中当作编码或计数依据；全部代码均由逐条语义阅读裁决。
5. 主题人数只表示26名本题作答者中的主动提及，不是经历率；未提及不表示没有经历。

## 一致与分歧

### 事件方向

Q8.1的事件方向有23/26条完全一致。三处分歧均是较长的“先说明初期距离，后叙述一个进入事件”的回答：

- `OT-R04-Q81`
- `OT-R08-Q81`
- `OT-R13-Q81`

归纳路径编码为 `ENTRY`，理论路径编码为 `MIXED`。最终保留 `ENTRY`：三条回答的题目焦点和转折落在后续进入事件，前段距离用边界、独处及地方参照代码保留。最终焦点方向为16条进入、4条距离、6条混合。独立review进一步指出，`MIXED`的6条并非同一语义：5条是进入后仍保留另一场景的距离，1条是先有距离、后转为进入。正式代码本因此用`MIXED_INCLUSION_AND_DISTANCE`和`SEQUENTIAL_DISTANCE_TO_ENTRY`分别标记。

### 概念粒度

| 分歧 | 裁决 |
|---|---|
| 听不懂语言与不了解本地话题是否同一边界 | 分开保留为 `SPOKEN_LANGUAGE_ACCESS_BARRIER` 与 `LOCAL_REFERENT_GAP`。会粤语仍有地方参照距离的回答说明二者不能合并。 |
| 任务中被邀、任务协作及任务后交往是否同一主题 | 分开保留。它们分别记录关系入口、共同完成事情和关系是否跨出任务场景。 |
| 课程差距、明确评分要求和隐性规则是否都属 hidden curriculum | 不合并。只有 `OT-R20-Q82` 明确说规则事前不知道，达到 `UNANNOUNCED_RULES` 阈值。 |
| 接受同伴解释是否属于文化中介 | 否。编码为朋辈规则解释或关系支持；开放题没有参与者跨群体解释、翻译或连接的直接行为证据。 |
| 加入班群是否证明平台促成归属 | 否。`OT-R03-Q81` 中线上群发生在线下合作之后，只保留为关系延伸。 |
| Q8.2提出支持是否等于支持缺失 | 否。统一标明“期望/建议不证明实际缺失”；`OT-R09-Q82`保留既有有效经验，`OT-R10-Q82`保留对既有支持的肯定。 |
| “进入朋友圈”“他人追随”能否形成机制代码 | 仅保留低置信度社会进入描述，不推断平台、领导力或关系深度。 |

## 正式代码本结果

综合代理最初提出46个正式代码：

- 44个以归纳代码为语义骨架，并吸收理论路径的同义标签、排除规则和理论边界；
- 新增 `EXPLICIT_BELONGING_OR_INCLUSION`，用于区分直接成员感与支持行动；
- 新增严格限定的 `UNANNOUNCED_RULES`，只覆盖明确的事前信息缺失。

代码本保留少数主题，包括体育认可、教师非正式倾听、被惦记、旧关系维系负担、线上群组入门、已获支持肯定和自信支持。没有因仅一人主动提及而删除。

独立review后新增`SEQUENTIAL_DISTANCE_TO_ENTRY`，并按`EXPLICIT_BELONGING_OR_INCLUSION`的排除规则删除3条只有邀请、日常活动或舒服感而没有直接成员感用语的代码。最终代码本为47个，直接成员感主题由21名修订为18名；持续并存5名与顺序反转1名分别报告。

## 置信度与相似叙述敏感性

最终52条编码中，39条为 `HIGH`、9条为 `MEDIUM`、4条为 `LOW`。置信度采用两路径中较低等级；短而明确的回答仍编码，只有其机制解释被限制。

若干长回答共享“小组邀请—解释—任务后用餐—进入感”或“不是能力不足—体系不同—需要时间”的结构。现有资料无法判断这是共同经验、题目塑形、填写情境或其他过程。因此：

- 不删除、不合并任何回答；
- 每条仍按独立回答者计数；
- 在逐回答文件中加上结构相似性敏感性警示；
- 不把这些相似叙述写成相互独立的机制复现或因果证据。

## 未获支持的理论标签

- **文化中介：** 没有直接行为证据，不实例化正式代码。
- **平台功能分工 / polymedia：** Q8.1和Q8.2各仅一条数字相关回答，均不足以支持平台组合或身份解释。
- **稳定学习者身份重构：** 可以记录既有优势获任务角色或参与者反对能力误读，但不能从一次事件推断长期身份变化。

## 输出审计

- `proposed_coded_responses.csv`：52行，Q8.1与Q8.2各26行；
- 综合代理原始`proposed_open_text_codebook.csv`为46个建议代码，保留在受限运行目录；
- reviewer闭环后的公开正式代码本为47个代码，正式主题表为47行，每题分母固定为26；
- 22条回答选有短、连续、逐字且不含姓名、学校或问卷序号的公共摘录；其余不选公共摘录；
- 原文和内部ID只留在受限代理目录，公共主题表只使用 `public_text_id`。
