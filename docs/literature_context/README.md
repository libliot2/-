# 文献研究上下文包

本目录用于把已完成的文献综述接入后续问卷、访谈、编码和解释工作。它保留完整综述与参考文献，同时提供一份便于快速调用的研究上下文和一份可按 `record_id` 追踪的紧凑证据索引。

## 推荐阅读顺序

1. **`research_context.md`**  
   先读这份中文摘要。它界定研究对象、主次研究方向、核心概念、已有发现、证据等级、研究空白和分析禁区，适合在设计问卷、整理访谈提纲和建立编码框架时反复查阅。

2. **`evidence_index.csv`**  
   再用证据索引核对具体来源。每行对应一项独立来源，并保留 canonical `record_id`；可按证据等级、对象、设计或研究方向筛选。经验性解释应先在此定位，再回到完整综述确认语境和限制。

3. **`literature_review.md`**  
   需要完整论证、证据分歧、方法建议或研究问题时阅读。该文件是 canonical `06_final_literature_review.md` 的逐字节副本，未改写实质内容。

4. **`references.bib`**  
   最后用于参考文献管理和引文导入。该文件是 canonical BibTeX 文件的逐字节副本；BibTeX key 与综述及证据索引中的 `record_id` 对应。

## 文件角色

| 文件 | 作用 |
|---|---|
| `research_context.md` | 供问卷和访谈分析使用的精简研究背景与解释边界 |
| `evidence_index.csv` | 73 项独立来源的紧凑、可筛选、可追踪索引 |
| `literature_review.md` | 完整中文文献综述及正文参考文献 |
| `references.bib` | 正文引用来源的 BibTeX 记录 |

## 使用原则

- 方向三和方向一是主要研究方向；方向二仅作为关系与互动过程的补充机制。
- A/B/C 表示研究对象与本项目目标人口的贴近程度，不等于方法质量。
- B、C 级研究不能改写成严格目标群体已经被证实的经历。
- `evidence_index.csv` 是检索入口，不替代完整综述中的限定语、证据分歧和方法限制。
